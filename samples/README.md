# Bundled synthetic samples

This directory holds the synthetic evidence the whole pipeline and the metrics
run on, offline. Everything here is generated by
`casebound/generate/synth.py` from the `office_intrusion` scenario and is fully
synthetic and safe: no real hostnames, no real IOCs, no working payloads
(AGENTS.md Hard rule 3).

## Files

- `synthetic_hayabusa.csv`: a Hayabusa-style `csv-timeline` (a verbose-profile
  subset). Columns are `Timestamp, Computer, Channel, EventID, Level,
  MitreTactics, MitreTags, RecordID, RuleTitle, Details`. Multi-value fields join
  with Hayabusa's broken-bar separator. Timestamps are local time with a UTC
  offset, as Hayabusa prints them. This is the evidence the ingest layer consumes.
- `ground_truth.json`: the known events and their MITRE ATT&CK technique ids that
  the metrics score the deterministic tagger against. Each labeled event records
  its `record_id` (matching a CSV row), the canonical UTC timestamp, the host,
  the principal, the normalized action and object, and its technique ids.

## The scenario

A multi-stage host intrusion:

1. Initial access: a phishing macro spawns an encoded PowerShell from Word
   (T1566.001, T1059.001).
2. Command and control: PowerShell pulls a stager over HTTPS (T1071.001, T1105).
3. Persistence: a Run key (T1547.001) and a scheduled task (T1053.005).
4. Credential access: the implant reads LSASS memory (T1003.001).
5. Lateral movement on a file server: a stolen-credential network logon
   (T1078.002), an ADMIN$ share access (T1021.002), and a remote service install
   (T1543.003). Each technique is grounded in evidence visible in its own row.
6. Collection and exfiltration: data is archived (T1560.001) and pushed to an
   external host (T1041).

A few benign events are interleaved so tagger precision is measurable.

## Regenerating

These files are committed so a clean clone has them without running anything. To
regenerate them byte for byte:

```
casebound generate
```

or with a different seed (changes the cosmetic record ids and synthetic hashes,
not the labeled events or technique set):

```
casebound generate --seed 42 --out-dir samples
```
